# GitHub publication checklist

- [ ] Confirm you have permission to publish all source files and diagrams.
- [ ] Review the repository for credentials and private/customer data.
- [ ] Create your own `.env` / `.env.dev` from the supplied template.
- [ ] Verify dependencies and startup commands in your target environment.
- [ ] Add a license only if you own or have permission to license the code.
- [ ] Add screenshots or a demo only after removing private information.
